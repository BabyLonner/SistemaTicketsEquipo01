Librerías de Backend (Python)
    Flask: Es el framework base obligatorio donde crearás las rutas y endpoints REST que devolverán los datos en formato JSON para tu campana.   
    PyJWT: Indispensable para proteger tus rutas; te permitirá extraer de forma segura el ID del usuario autenticado para consultar únicamente sus notificaciones en la base de datos.   
    mysql-connector-python (o PyMySQL): La librería de conexión para enviar las sentencias SELECT COUNT, INSERT y UPDATE hacia tu base de datos MySQL.   
    datetime (Nativa): Módulo interno de Python fundamental para capturar el tiempo exacto de un evento y almacenarlo en el campo de base de datos created_at que te exige la guía.  

Librerías y APIs de Frontend
    Fetch API (Nativa de JavaScript): La guía especifica explícitamente el uso de peticiones AJAX/fetch para obtener el contador en tiempo real y marcar notificaciones como leídas sin recargar la página web. No necesitas instalar librerías externas como Axios o jQuery.   
    Bootstrap (u otro framework CSS): Recomendado en el documento para el desarrollo frontend. Te resultará muy útil para implementar rápidamente la estructura del menú, el componente visual del ícono de la campana y la tarjeta desplegable (dropdown) que mostrará la lista de notificaciones.   
    Librería de Íconos (Opcional pero recomendada): FontAwesome o Bootstrap Icons para obtener un ícono de campana profesional y agregarle dinámicamente un distintivo (badge) rojo utilizando CSS y tu lógica de JavaScript cuando el valor del contador sea mayor a cero.
